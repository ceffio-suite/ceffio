01 — Modules

What you install

Every building block is a module: enabled at install time, or added later — from the CLI or from the console.

  • Files and documents

    Nextcloud: sync, sharing and online editing, on storage that stays with you.

  • Mail

    Stalwart: SMTP and IMAP, filters, webmail. The CLI checks the DNS records deliverability depends on.

  • Video meetings

    Nextcloud Talk with its SFU and TURN server: audio and video travel over your network, not a third-party platform's.

  • Document editing

    ONLYOFFICE: documents, spreadsheets and presentations edited together, without leaving the suite.

  • Team chat

    Nextcloud Talk: conversations and threads, behind the same sign-in as files.

  • Secrets vault

    OpenBao: credentials generated during install are sealed there, never asked for at the terminal.

  • Recording and transcription

    Meetings are recorded, then transcribed track by track on your own machine — nothing sent to an external service.

  • Administration console

    The real state of services, certificates and accounts, plus a documented JSON API.

  • Identity and SSO

    Keycloak: one account directory for every module, wired over OIDC.

02 — Installation

How it goes

Three moments, from an empty server to a suite in production.

  1. Install the CLI

    One Go binary on your Linux server. It installs K3s and deploys the suite by talking straight to the Kubernetes API — no operator in between.

  2. Run the installation

    ceffio install deploys the modules, issues certificates and generates credentials, then seals them in the vault. The command is idempotent: running it again repairs, it does not break.

  3. Administer from the console

    Service, certificate and account state is computed from the cluster, never copied by hand. The same actions exist as JSON.

03 — Guarantees

Serious, and checkable

Promises an operator can verify in person, in the repository as well as on the machine.

  • Automatic HTTPSCertificates issued and renewed by cert-manager, with a choice of two validation methods: HTTP-01 or DNS-01.
  • Machine-readable SBOMceffio sbom writes a CycloneDX document covering everything the installation can run, images pinned by digest.
  • Vulnerability scanEvery release is scanned with Grype; exceptions are written down, justified and versioned in the repository.
  • Backupsceffio backup and ceffio restore: databases, secrets and volumes.
  • Documented APIThe console's JSON contract is described in the repository, along with the authentication it requires.
