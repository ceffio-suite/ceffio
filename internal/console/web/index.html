Administration key

The administration key lives in the secrets vault (OpenBao), at entry kv/ceffio/console/api — and nowhere else. It is only stored in your browser.

TOKEN=$(kubectl get secret openbao-installation -n ceffio-vault -o jsonpath='{.data.token}' | base64 -d)
kubectl exec -n ceffio-vault openbao-0 -- \
  sh -c "BAO_ADDR=http://127.0.0.1:8200 BAO_TOKEN='$TOKEN' bao kv get -field=key kv/ceffio/console/api"

The administration token is read from the openbao-installation Secret (namespace ceffio-vault). It is the installation token that administers the vault; the one named openbao-token is reserved for services and does not grant access to this entry.

The token is a Kubernetes Secret, not a file inside the pod: it must be read with kubectl and passed in, as above. Copying it into the pod by hand is what the previous version of this page told you to do, and it fails — nothing creates that file.
