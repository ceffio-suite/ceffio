Clé d'administration

La clé se trouve dans le Secret Kubernetes ceffio-console-key. Elle n'est stockée que dans votre navigateur.

kubectl get secret ceffio-console-key -n ceffio-system -o jsonpath='{.data.key}' | base64 -d
