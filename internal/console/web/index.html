Administration

Un seul compte administre la plateforme : Nextcloud, le serveur de mail et cette console. Il est créé dans l'annuaire d'authentification (Keycloak), donc la même identité fonctionne partout — et la rotation du mot de passe s'y propage.

Interfaces d'administration

La console ne réimplémente pas ces interfaces : elle vous y conduit. Celle de Nextcloud connaît son catalogue d'applications (catégories, compatibilité, avis) mieux qu'une page reconstruite ici.

Rotation du mot de passe

Le mot de passe est généré ici puis appliqué à chaque système. Il est affiché une seule fois : notez-le avant de quitter cette page. Aucun système ne peut le relire ensuite — seul un empreinte irréversible est conservée, c'est ce qui protège le compte.

Ce mot de passe ne sera plus affiché. Copiez-le maintenant.

Clé d'administration

    
La clé se trouve dans le Secret Kubernetes ceffio-console-key.
    Elle n'est stockée que dans votre navigateur.

    

      kubectl get secret ceffio-console-key -n ceffio-system -o jsonpath='{.data.key}' | base64 -d
