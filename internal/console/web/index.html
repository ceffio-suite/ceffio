External applications deployer (HaRP)

Nextcloud runs some features as containers rather than PHP code. It cannot start one by itself: it needs a deployer. HaRP is that deployer, and it speaks the Kubernetes API directly.

Everything below depends on this. Removing it also removes the applications it deployed and their volumes.

Live transcription in Talk

Transcribes speech live during a call, on this server, with open source speech models. Nothing is sent to a third party.

This is a heavy optional component. It downloads about 9 GB (container and speech models) and needs around 16 GB of RAM for one or two simultaneous calls. It is not installed by default, and its two settings cannot be changed once it is installed — the app has to be removed and installed again. That is why it lives here rather than in the initial deployment.

Uninstalling removes the app, its workload, its service and its volume — including the downloaded models.

Administration

A single account administers the platform: Nextcloud, the mail server and this console. It is created in the authentication directory (Keycloak), so the same identity works everywhere — and the password rotation propagates from there.

Administration key

    
The administration key lives in the secrets vault (OpenBao), at entry
    kv/ceffio/console/api — and nowhere else.
    It is only stored in your browser.

    

      TOKEN=$(kubectl get secret openbao-installation -n ceffio-vault -o jsonpath='{.data.token}' | base64 -d)

      kubectl exec -n ceffio-vault openbao-0 -- \

        sh -c "BAO_ADDR=http://127.0.0.1:8200 BAO_TOKEN='$TOKEN' bao kv get -field=key kv/ceffio/console/api"
    

    
The administration token is read from the
    openbao-installation Secret (namespace
    ceffio-vault). It is the installation token that
    administers the vault; the one named openbao-token is reserved
    for services and does not grant access to this entry.

    
The token is a Kubernetes Secret, not a file
    inside the pod: it must be read with kubectl and passed in, as
    above. Copying it into the pod by hand is what the previous version of this page told you
    to do, and it fails — nothing creates that file.
